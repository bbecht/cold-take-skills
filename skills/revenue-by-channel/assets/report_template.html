How the solver works and what it assumes

Each channel's deal flow is taken from this file: deals per month, win rate and average won deal. More spend brings more deals, with diminishing returns: deals grow with spend raised to the saturation power. That curve is split into 20 straight steps, each returning less than the one before, which makes this a linear program. With one budget line and falling returns per step, filling the highest-return steps first is the exact optimum.

Worst, base and best cases use the same recommended mix. Base uses each channel's actual win rate. Worst and best use the low and high end of a 90% confidence range around it, and a higher or lower saturation. Channels with few deals get wide ranges on purpose.

This file has no spend data of its own. Every cost figure comes from what you type in. Revenue lands after the sales cycle, so the 12-month figures assume the new mix runs long enough for deals to close.
